# 动态数据展示清理与复验

日期：2026-10-18。三文鱼指出洞察详情的评分依据、AI建议仍直接显示内部字段和字典，要求检查同类问题。本轮由Codex直接实施，只调整前端显示，不修改评分、持久化内容或后端。

## 根因与修复

评分服务在同一个说明字段中拼接确定性审计前缀与中文解释，页面将整个字段分别放入评分依据和AI建议。上一轮固定文案扫描未覆盖这类动态值。

- 对已知评分格式提取中文说明，保留数值、限制和证据不足的结论。残缺或嵌套诊断显示“暂无可读的评分说明”，不重算评分、不生成新解释。
- 决策、分析类型、情感、用户类型与主题显示为业务名称；未知人群显示待确认。
- 反馈详情保留原话和追溯编号，移除供模型处理的拼接文本及内部选取规则串。
- 错误提示包括展开详情统一经过展示转换，避免中文错误夹带字段赋值、堆栈、路径或序列化内容。
- 需求与文档中的已知分类标记、指标内部字段写法转换为业务名称，同时覆盖只读正文和编辑框。URL保留原样，原始反馈和官方引文不适用说明过滤。未编辑的草稿字段保存时仍发送原值，有回归验证。
- 未知分类仍阻止保存；内容复核、未验证、模拟及未测量边界继续保留。
