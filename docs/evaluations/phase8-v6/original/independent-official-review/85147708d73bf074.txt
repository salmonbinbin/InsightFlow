What is the Dropbox file size limit?
Updated Jun 17, 2026
In this article
The information in this article applies to all Dropbox customers.
The maximum file size you can upload to Dropbox is 2 TB (2,199,019,061,248 bytes).
Uploading files larger than 375 GB in a web browser may cause timeouts or interrupted uploads. Large file uploads may also be unreliable on mobile devices due to operating system limitations. For the best results, use the Dropbox desktop app or the Dropbox API.
See the FAQs below for best practices when uploading large files on dropbox.com.
Notes:
All files uploaded to your Dropbox account must be smaller than your storage space. For example, if your account has 2 GB of storage, you can upload one 2 GB file or mutliple smaller files that total 2 GB.
If you're over your storage limit, Dropbox will stop syncing.
Not using Dropbox yet? See how Dropbox makes syncing files easy.
FAQs about upload limitations
Which file types can I upload to Dropbox?
You can upload most file types, but there are some exceptions, like certain types of symlinks, .lnk files, and web-based files.
How do I upload large files on dropbox.com?
If the file you want to upload is larger than 375 GB, download the Dropbox desktop app on your computer and upload it from there. You can also compress the file to reduce the size to less than 375 GB and then upload it on dropbox.com.
Note: For the best results, use the Dropbox desktop app or the Dropbox API when uploading large files.
How do I upload files to Dropbox?
You can upload files and folders to Dropbox on dropbox.com or through the desktop app. You can also upload photos and videos from your mobile device using the Dropbox mobile app.
Are there any restrictions on file or folder names?
Yes, there are guidelines for naming files and folders:
Don’t use special characters in file names.
Don’t add a space at the end of a file or folder name.
It’s also recommended to keep file and folder paths under 260 characters.
