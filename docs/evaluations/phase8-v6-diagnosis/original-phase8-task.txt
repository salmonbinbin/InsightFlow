新增：

# Research Agent

主要用于针对某个 Product Insight 做外部产品研究。

例如：

Insight：
用户希望支持批量图片上传。

用户可以点击：

Research Competitors

Research Agent 自动研究：

- 竞品是否支持该功能
- 功能如何设计
- 限制条件
- 典型用户体验
- 产品差异
- 潜在机会

输出：

Competitor Findings
Product Patterns
Strengths
Weaknesses
Differentiation Opportunities
Sources

━━━━━━━━━━━━━━━━━━
五、Research Agent 输入
━━━━━━━━━━━━━━━━━━

输入必须包含：

- insight_id
- insight title
- insight summary
- pain point
- affected segment
- representative evidence summary
- PM decision（如果已有）
- research question / scope

不要直接把全部 Raw Feedback 无限塞给 Research Agent。

━━━━━━━━━━━━━━━━━━
六、Research Agent 输出
━━━━━━━━━━━━━━━━━━

建议 Structured Output：

{
  "summary": "...",
  "competitors": [
    {
      "name": "...",
      "feature": "...",
      "strengths": [],
      "weaknesses": [],
      "source_refs": []
    }
  ],
  "market_patterns": [],
  "opportunities": [],
  "risks": [],
  "confidence": 0.0
}

必须 Schema Validation。

━━━━━━━━━━━━━━━━━━
七、Research Source Grounding
━━━━━━━━━━━━━━━━━━

Research Agent 的结论必须关联来源。

必须保存：

- source URL / source id
- title
- provider / domain
- retrieved_at
- supporting finding

禁止：

Research Agent 无来源地写：

“所有竞品都支持这个功能。”

如果没有来源：

必须显示：

Not verified / insufficient evidence

- Audit

只有真正调用成功才算完成。

十六、外部写操作必须 Human Approval

# Human Approval

↓

↓
