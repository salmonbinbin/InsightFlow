# InsightFlow · AI 产品需求洞察 Agent

将用户反馈、访谈、客服记录等非结构化内容转化为可追溯的痛点、需求聚类、洞察和产品行动。

目标用户：需要周期性处理数百至数千条反馈的 AI / 互联网产品经理。
核心原则：No Evidence, No Insight；AI recommends, PM decides。

## 价值与流程

上传反馈 → 结构化分类和意图提取 → 向量表示 → 算法聚类 → LLM 语义复核 → 洞察 → 原始证据 → 机会评分 → PM 审核 → Requirement → PRD 草稿。

AI 负责理解语言和生成有依据的建议；程序负责计数、评分、持久化和证据检查；PM 负责商业价值与最终优先级。

## 三层范围

- 后端 V0.1（本次）：FastAPI、PostgreSQL Project/Feedback 模型、迁移、CSV 导入和查询。
- Sprint 1：Feedback → Insight，包括分类、Embedding、层次聚类、语义复核、证据、基础评测及四个页面。
- V1：增加机会评分、人工调整、需求池、可编辑 PRD、评测看板。

V1 不包含爬虫、实时流、企业权限、自动上线、Jira/飞书/Notion 集成和完整多 Agent。初期架构采用单 Agent 与多个工具；V0.1 尚未连接任何模型。
