## Phase 2 — Embedding + Semantic Clustering（2026-10-12）

| 事项 | 本次选择 |
|---|---|
| 向量存储 | `feedback_embeddings.embedding` 用 `JSON` 列（PG 11+ 原生 JSONB），不引入 pgvector 扩展，保证 SQLite 测试可跑通；同 `(analysis, model)` 由 `UNIQUE` 约束 + PG `ON CONFLICT DO NOTHING` 避免重写 |
| Embedding 维度 | `EMBEDDING_DIMENSION` 默认 128；维度不匹配时抛 `EmbeddingDimensionMismatch`，不静默接受 |
| Embedding 模型 | `LocalHashEmbedder`（SHA-256 桶 + L2 归一，测试与默认）与 `RemoteEmbedder`（OpenAI 兼容，env 缺失时回退 local）；通过 `EMBEDDING_API_KEY` + `EMBEDDING_BASE_URL` 启用远程 |
| 聚类算法 | 层次聚类（agglomerative）+ cosine distance；linkage 通过 `CLUSTER_LINKAGE`（default `average`），阈值通过 `CLUSTER_DISTANCE_THRESHOLD`（default 0.45） |
| 簇来源 enum | `algorithmic` / `llm_review` / `outlier`；split 后保留 `parent_cluster_id` 供审计 |
| LLM 复核 | KEEP / SPLIT / MERGE / OUTLIER；payload 严格校验（action、groups、outlier_ids、merge_with_cluster_index）后才落库；payload 不合法保持 algorithmic 不变，run 标 `partial_failed` |
| Run 复用 | 直接复用 `analysis_runs`，`run_type='clustering'`；状态机同 Phase 1；clustering 阶段幂等，COMPLETED 也可重试 |
| 输入快照 | 沿用 Phase 1 `input_feedback_external_ids`，retry 不扩大输入 |
| Raw 保护 | `feedbacks.content` 全程只读；不写、不级联、不重写 |
| 评测指标 | 簇 Purity (micro/macro) / Coverage (GT 簇 ≥50% 成员被同簇覆盖) / Fragmentation (每 GT 簇被切几段) / Over-merge (混合 ≥2 GT 标签的预测簇比例) |
| 标签状态 | `data/golden_dataset.csv` 的 `gt_cluster` **未人工复核**，仅作阈值实验初始参考 |
| E2E 脚本 | `scripts/run_clustering_e2e.py`：独立临时 PG + alembic upgrade + HTTP 全链路（支持 `--stub-llm` 离线） |
| 阈值实验脚本 | `scripts/run_clustering_eval.py`：synthetic 模式隔离 Phase 1 噪声；full 模式跑真 LLM |
| 与长期总纲差异 | Embedding 用 JSON 而非 pgvector；LLM 复核一次 LLM 调用（非 multi-agent）；不引入 Insight / Evidence / Opportunity / Frontend / PRD / MCP / Multi-Agent |


## 2026-10-12 — Phase 2 独立验收后的修正（替代上节相冲突选择）

1. **正式存储改为原生pgvector**：0007将JSON转vector，DB核对记录维度与实际维度并拒绝零向量。SQLite保留JSON测试后端；早先JSONB/pgvector描述不准确，保留历史并以0007实测为准。
2. **本地哈希仅作测试**：Settings统一读取.env/env，只有local-hash-v1可使用local；远程模型缺少配置报错，不得默默用远程名写哈希向量。
3. **输入与配置快照**：analysis_runs.cluster_config记录classification_run_id、embedding model/dimension、threshold/linkage、review model/enabled。未完成Run仅同配置Retry；completed Retry是无副作用返回，重新评估创建新Run。旧无快照Run拒绝猜测来源。
4. **成员分区与Review**：严格KEEP/SPLIT/MERGE/OUTLIER；MERGE仅指向KEEP，源成员真实转移；全OUTLIER允许groups=[]；所有成员最终恰好一次。Prompt v1留存，本次v2/v3试验亦留存，当前v4纠正交叉merge、空组和不相关兜底簇。
5. **计数口径**：success_count是反馈数；候选簇数记cluster_config，最终簇数只计非空输出。negative_ratio仅negative，mixed不计；Review计量累加失败尝试、缓存输入tokens，缺失标unknown。
6. **距离口径**：cosine distance=1-similarity，范围0—2；当前阈值配置0—1，distance严格小于threshold合并。更高阈值更容易合并，不把历史0.45或小集0.30宣称最佳。
7. **验证工具**：真实网络验收用verify_phase2_http.py（独立临时PG）；旧run_clustering_e2e.py仍是TestClient/local hash实验，不是网络或语义Embedding证明。新迁移坏旧值原子拒绝，绝不静默删向量。pgvector扩展downgrade不删除共享扩展。
8. **结论**：按最新用户验收Gate为FAIL；真实Embedding、正式质量和Git仍未关闭，STOP。详细证据见[独立验收报告](17-Phase2独立验收与修复报告.md)。
