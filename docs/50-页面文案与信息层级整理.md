# 页面文案与信息层级整理

日期：2026-10-18。三文鱼要求清除页面上的接口路径、代码和测试版本式说明，页面应简洁易懂。本批由 Codex 直接修改前端，不改变 Phase8 后端能力或既有验收结论。

## 本批变化

- 清理导航及页面中的阶段号、MVP、工作包、接口地址、请求方法和数据结构名称。
- 列表、详情、决策按钮、需求字段、评测指标与状态统一为中文业务名称。来源渠道如 `in_app`、`interview` 仅转换显示，存储值不变。
- 运行编号、模型/提示词版本、生成信息和原始诊断收进默认折叠的详情；来源链接、引文和可追溯信息继续保留。
- 反馈页保留“仅当前页”的搜索/排序范围，移除大段开发说明。窄屏优先展示反馈编号、内容和来源，用户与时间在反馈抽屉中仍可查看；桌面完整列不变。
- 保留未验证、待人工复核、模拟任务、尚未测量等必要状态，未将它们改成通过、真实集成或零值。
- 现有界面测试仅同步文案断言；另修正研究测试辅助函数不匹配的返回类型，未移除原有行为检查。新增四项展示层测试，检查折叠追溯、未知状态、错误文案与待复核提示。
