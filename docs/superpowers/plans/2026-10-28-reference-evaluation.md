# 人工参考答案评测与数据准备实施范围

用户已选择先完成数据与人工评测，真实Embedding待配置后验收。沿用54号B/C批次，单写入者Codex直接实施；本轮不更改Phase1/2/3业务逻辑、历史迁移或Prompt。

设计：现有评测页增加人工参考答案模式。下载当前已结束Run的CSV模板，标签留空，不泄露模型预测作为标准答案。模板绑定项目、Run、反馈ID和原文hash，含供人阅读的原文。导入要求每行reviewed和审核人，允许明确的子样本，拒绝未知/重复ID、串项目、原文漂移、非法/未完成标签。样本分母与原Run分母分别显示。分类评估类型与严重度，意图自由文本保持未测量；聚类复用既有纯度/覆盖/碎片化指标，不将逐例结构通过写成语义正确。

采用独立reference_review服务、schema/API模块与页面组件，复用现有runner的计算函数，在一次事务中写评测、标签快照和指标；不复制Raw、不改源分析。参考标签与审核人按显式上传行为保存，标记为用户声明已复核，不冒充正式项目验收。保留每次导入版本及逐例预期/实际值，支持报告回看；无迁移、无新增依赖、无模型调用。

模板中外部可控文本用可逆CSV安全转义，原文hash基于未转义文本，避免公式执行及编辑器换行造成静默改写。CSV限制2MiB、最多10000行；在写入前完成所有验证。上传失败不留下半份报告。

- [ ] 实现服务/schema/API和逐例报告读取，验证不修改Raw和历史报告。
