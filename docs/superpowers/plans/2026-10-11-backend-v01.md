# InsightFlow 后端 V0.1 实施计划

**Goal:** 归档讨论并交付可运行的项目、反馈存储和 CSV 导入后端。
**Architecture:** FastAPI 路由、Pydantic 校验、CSV 解析服务、SQLAlchemy 持久化；Alembic 管理 PostgreSQL 表结构。
**Tech Stack:** Python 3.12+、FastAPI、SQLAlchemy 2、psycopg 3、Alembic、pytest。
