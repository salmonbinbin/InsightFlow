# 评测实现与边界

已实现分类/聚类参考评测、洞察证据存在性检查、逐例追踪和历史比较。`run_check.py`支持任意有输入快照的项目运行结构检查；没有参考标签时语义指标保持未测量。

`reference_review.py`提供当前运行CSV模板、人工标签导入、分类/严重度及聚类指标计算，并原子保存标签/审核人/已有结果快照。前端评测页可下载、上传、查看逐条对照。导入标签标记为用户声明已复核，不是正式验收；意图没有受控词表，保持未测量。

参考答案必须绑定项目、Run、反馈ID和原文hash；上传前校验来源、标签及完整性。标签和审核人会保存，Raw Feedback不会复制到评测表；旧报告不覆盖。现有12条内置标签仍未经人工验收。真实Embedding、洞察语义复核和PRD质量验收不能由运行完整率代替。

使用与验证详见`docs/55-人工参考评测与数据准备交付.md`（项目根目录相对路径）。
